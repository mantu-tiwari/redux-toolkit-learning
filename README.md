# 📝 Redux Task Manager

A simple and responsive Task Manager built with **React**, **Redux Toolkit**, and **Tailwind CSS**. This project was created to understand the fundamentals of Redux Toolkit by implementing a complete CRUD application with global state management.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/redux-task-manager.git
```

Navigate to the project folder:

```bash
cd redux-task-manager
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
